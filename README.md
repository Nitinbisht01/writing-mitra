## 📖 About The Project

**Writing Mitra** is a full-stack creative writing platform built for poets,
storytellers, and language lovers. Users can publish poems, shayri, ghazals,
and short stories as blogs, participate in writing competitions, and get
AI-powered writing suggestions via the Cohere AI API — all in one place.

The platform was built to solve a simple problem: there is no dedicated Indian
creative writing community where writers can share, compete, and improve. 
Writing Mitra fills that gap.

## 🌟 Features

| Feature | Description |
|---|---|
| 📝 **Publish & Blog** | Write and share poems, shayri, ghazals, and short stories |
| 🏆 **Competitions** | Enter writing competitions and get ranked as a winner |
| 🤖 **AI Writing Assistant** | Cohere AI provides real-time suggestions inside the editor |
| 📂 **Content Categories** | Posts organized by type — poem, shayri, ghazal, story |
| 📰 **Content Feed** | Browse all writings in a clean categorized feed |
| ✏️ **Full CRUD** | Create, edit, update, delete your own posts |
| 👤 **User Management** | Register, login, manage your profile |
| 📧 **Email Notifications** | JavaMail SMTP for competition and activity updates |
